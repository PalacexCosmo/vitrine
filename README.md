# Vitrine Le Palace / Cosmo

Page publique des écrans partenaires, servie par GitHub Pages : https://palacexcosmo.github.io/vitrine/?ecran=<nom>

- `index.html` : lecteur de playlist (généré depuis le dépôt affichage, ne pas modifier à la main).
- `ecrans/<nom>.json` et `medias/` : publiés automatiquement par le serveur d affichage toutes les 15 minutes.
